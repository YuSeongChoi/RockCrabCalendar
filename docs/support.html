바위게캘린더 지원

앱 사용 중 문제가 있거나 개선 의견이 있다면 GitHub Issues로 알려주세요. 재현 방법과 기기/iOS 버전을 함께 남기면 더 정확하게 확인할 수 있습니다.

문제 신고하기

문의 전 확인할 내용

  • 앱 버전과 iOS 버전
  • 문제가 발생한 화면과 동작 순서
  • 가능하다면 오류 화면 스크린샷

주요 기능

  • QWER 공식 일정 확인
  • 개인 일정 추가 및 일정별 알림 설정
  • 일정별 감정, 메모, 사진 기록
  • 일정 검색과 홈 화면 위젯

광고 및 구매

  • 광고 제거 인앱결제는 App Store 계정 기준으로 복원됩니다.
  • 구매 후 광고가 계속 보이면 앱 재실행 후 구매 복원을 시도해 주세요.
  • 광고 관련 데이터 처리 내용은 개인정보처리방침에서 확인할 수 있습니다.
